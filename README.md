# 胡欢 · 网页版简历

基于 `胡欢简历-0707.pdf` 转换的现代极简风格单页简历,适配桌面/平板/手机,并内置一键导出 PDF 功能。

## 文件说明

- `index.html` —— 主交付物,单文件网页简历(HTML + 内嵌 CSS + 内嵌 JS,无外部依赖,离线可打开)

## 本地预览

### 方式一:直接双击打开

直接双击 `index.html` 即可在默认浏览器中查看。所有资源内嵌,不依赖网络。

### 方式二:本地服务器(推荐,功能更完整)

```bash
# 进入本目录
cd huan-resume

# 启动 Python 静态服务器
python -m http.server 8000

# 浏览器访问
# http://localhost:8000
```

## 导出 PDF

1. 在浏览器中打开 `index.html`
2. 点击页面**右上角"导出 PDF"按钮**(或直接按 `Ctrl + P` / `Cmd + P`)
3. 在打印对话框中将"目标打印机"选择为 **"另存为 PDF"**
4. 调整设置:
   - 边距:**无** / **最小**(已针对 A4 优化)
   - 背景图形:**勾选**(以保留颜色与边框)
5. 保存

> 打印样式已优化:隐藏导航栏与按钮、链接 URL 自动追加展示、A4 排版紧凑、强调色保留。
